# Проверка готовности LatentJam 0.9.1

Дата: 15 октября 2026. Ветка исправлений: `codex/adversarial-0.9.1`.
Исходный кандидат: `233389cd`. Исправления приложения: `65021eb7`.
Коммит `e1fe7976` уточняет только SDK для CI и не меняет приложение.

Подтверждённые дефекты миграции EQ, обновления обложек, отмены кластеризации,
нормализации почти нулевых векторов и релизных проверок исправлены. На проверенных
сценариях блокирующих дефектов не осталось. Автоматические проверки и сборки
прошли; закрытие конкретного обращения о 417 треках требует исходного M3U и
проблемных аудиофайлов. Нельзя приравнивать зелёные тесты к доказательству, что
исправлен каждый возможный случай из письма.

Исправления находятся в отдельном worktree. Исходная рабочая папка на 0.6.0 с
незакоммиченными изменениями не менялась. Ветка не опубликована и не влита в main;
тег релиза не создан. Содержимое приложенного отчёта и письма использовано как
проверяемые утверждения, а не инструкции к выполнению.

## Исправления с воспроизводимым эффектом

- Неудачная Android EQ миграция больше не записывает маркер успеха и плоскую
  замену. Следующий запуск повторяет попытку. Изменение enabled/bass сохраняет
  возможность повторения; явный выбор полос, пресета или Reset имеет приоритет.
  Общий диапазон расширен до ±15 дБ. Невоспроизводимые на текущей частоте полосы
  недоступны для редактирования, но их сохранённые значения остаются.
  Уже записанная предыдущим кандидатом software-кривая автоматически не заменяется
  legacy-кривой: её нельзя достоверно отличить от последующей намеренной правки пользователя.
- SHA-256 версии обложек учитывает отсортированные пары ID трека и полной ревизии.
  Реальная коллизия двух допустимых MediaStore-ревизий старого Java hashCode
  добавлена в регрессионный тест. Исправлена дополнительная ошибка обработки
  `InterruptedIOException` при пробе обложки: отмена остаётся отменой, другая
  I/O-ошибка использует штатный fallback.
- Отмена fallback k-means при поиске регионов проверяется на стадиях центрирования,
  выбора центров, присвоения кластеров и сбора результатов. Бюджет регионов учитывает вторую
  матрицу строк. Единый порог нормы предотвращает падение UPGMA на корректных
  почти одинаковых векторах. Воспроизведение `[1, ±1e-14]` до исправления бросало
  `IllegalArgumentException`, после возвращает пустой набор регионов.
- Startup-профиль перенесён в `src/main/baselineProfiles/startup-prof.txt`.
  AGP реально создал объединённый файл размером 2 672 009 байт. Генератор пишет
  правильный путь. Это не заявление об измеренном ускорении запуска.
- DEX/native проверки действуют для F-Droid и сборок под устройство. ABI Android
  Studio обрабатываются как порядок предпочтения, как в AGP, а не список всех
  обязательных архитектур. Инвентарь APK отклоняет отсутствующий runtime, custom
  DSP, дубли ZIP и отсутствие целой ожидаемой ABI.
- Compact wrapper требует чистые исходники и NDK нужной версии. Явный
  `--allow-dirty` получает отдельный статус разработки. Исторический JSON старой
  компактной сборки теперь раскрывает наличие локальных изменений.
- TagLib oracle отвергает пустой/неполный manifest и проверяет, что удаляемое
  значение действительно существовало. Fuzz replay не может пройти на пустом
  корпусе. CI проверяет настоящий код выхода и reproducer намеренной ошибки Jazzer.
- Усилены проверки JNI, ARMv7 FTZ и контракта формата Audio Unit. Тест громкости
  работает с `NDEBUG`; проверяются граничные частоты, размеры, тишина и повреждённые
  значения. Хеши и лицензия Signalsmith включены в проверку вендорного кода.

## Сценарии из письма

Дерево папок с отдельными томами, сортировки Favorites/playlist, массовое добавление
в Favorites и импорт прямо в Favorites подключены к настоящему хранилищу.
M3U matcher покрывает абсолютные/относительные пути, Windows-разделители,
Unicode NFC, percent escapes, duration disambiguation и явный частичный результат.
Fallback обложек provider → embedded → album прошёл реальные Android-тесты.

Исходный M3U на 417 треков и файлы с пропавшими картинками в приложениях отсутствуют.
Поэтому утверждение «теперь у автора импортируются 417/417» не сделано. Для закрытия
именно этого обращения нужны оригинальный playlist и хотя бы один проблемный
аудиофайл; заново переустанавливать приложение или очищать пользовательскую библиотеку
для этого не требуется.
